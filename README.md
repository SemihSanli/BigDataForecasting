## Teknoloji Stack

### Backend

| Teknoloji | Amaç |
|-----------|------|
| .NET 9/10 | Web API |
| Entity Framework Core | Veri erişimi (Code First) |
| ML.NET | Satış tahminleme (Forecasting) |
| Redis | Cache + Token Blacklist |
| JWT + Refresh Token | Authentication & Authorization |
| Serilog + Seq | Yapılandırılmış loglama |
| Mapster | Entity-DTO dönüşümü |
| FluentValidation | Input doğrulama |
| Scalar | API dokümantasyonu (Swagger alternatifi) |
| Docker | Containerization |
